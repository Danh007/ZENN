# ZENN

**Creator:** Denis Beigel
**Course:** Mobile Game Development, Shenkar

## The game in one sentence
A game about balancing a sphere, reaching new checkpoints, solving puzzles and learning.

## How to open and build
1. Open the project in Unity 6.3 LTS (the exact version is on Moodle).
2. File → Build Profiles → Android → Switch Platform.
3. Build and run on an Android phone.
